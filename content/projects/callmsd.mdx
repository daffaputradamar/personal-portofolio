**CallMSD** is a call-centre assistant for the dealer network. It answers the questions that used to wait for a supervisor to look something up.

## What it does

- **Documents and data together**: answers draw on guideline documents and on tabular data such as stock and programme details.
- **Managed knowledge**: an admin keeps the assistant's knowledge current as programmes change.
- **Read-only**: the assistant reports information and cannot modify any data.
- **Usage view**: a dashboard shows what is being asked.

## Approach

A question about a rule and a question about a number need different handling. The agent decides whether to retrieve a passage or query the data, then answers from whichever source applies, and it only ever reads.
